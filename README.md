# Автоимперия — серверная версия

## Что внутри
- `server.js` — Node.js API + SQLite.
- `public/index.html` — обновлённый Mini App.
- `autoimperiya.db` создаётся автоматически после первого запуска.
- Telegram `initData` проверяется на сервере по HMAC-SHA-256.
- Баланс, открытия, гараж, история и операции с рынком хранятся на сервере.
- Результат кейса выбирается сервером.
- Повторная отправка произвольного автомобиля в `keep/sell` не проходит: сервер хранит незавершённый результат кейса.

## Запуск
1. Установи Node.js 20+.
2. В этой папке выполни:
   `npm install`
3. Создай переменную окружения `BOT_TOKEN` с токеном бота из @BotFather.
4. Запусти:
   `npm start`
5. Открой `http://localhost:3000` для проверки сервера.

## Telegram Mini App
Укажи HTTPS-адрес этого сервера как URL Mini App у своего Telegram-бота. В Telegram Mini App браузер передаст `Telegram.WebApp.initData`, а сервер проверит его перед созданием/получением аккаунта.

## Важно
Никому не отправляй `BOT_TOKEN`. Не вставляй его в `index.html`.
